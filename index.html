Cómo funciona Política de privacidad
Arquitectura

Privado por diseño.

[ local ]

Inferencia on-device

El modelo de lenguaje corre íntegramente en tu iPhone. Tus mensajes no salen del dispositivo para ser procesados.

[ memory ]

Memoria local

El contexto y la memoria semántica se almacenan solo en tu dispositivo, bajo tu control.

[ web ]

Acceso web puntual

Cuando una respuesta necesita información actual, se realiza una consulta web directa desde tu iPhone. Solo se envía la consulta necesaria.

[ no_acct ]

Sin cuentas

No hay registro ni inicio de sesión. No recopilamos identidad, correo ni perfil de usuario.

Tus datos

Lo esencial, en claro.

  • →El procesamiento es local. La generación de respuestas ocurre en tu iPhone mediante un modelo de IA embebido.
  • →Solo sale la consulta web. Cuando se necesita información de internet, se envía únicamente el texto de búsqueda necesario, directamente desde tu dispositivo.
  • →No hay backend propio. No operamos servidores que reciban o almacenen tus conversaciones.
  • →Tú mandas. El historial y la memoria viven en tu dispositivo y puedes borrarlos.
